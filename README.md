- **Кейс-задача № 3:** класс `WORKER` на C++17

## Что делает программа

Класс `WORKER` описывает сотрудника организации и хранит четыре поля:

| Поле | Тип | Описание |
|---|---|---|
| Фамилия и инициалы | `std::string` | например, `Иванов И.И.` |
| Должность | `std::string` | например, `Доцент` |
| Зарплата | `double` | оклад в рублях |
| Год поступления на работу | `int` | например, `2015` |

Программа:

1. вводит данные сотрудников с клавиатуры (или загружает из файла/демо-набора);
2. запрашивает порог стажа;
3. выводит фамилии сотрудников, чей стаж в организации **строго больше** введённого значения;
4. если таких сотрудников нет — выводит соответствующее сообщение.

Данные адаптированы под профильное подразделение организации: должности в демо-наборе
соответствуют штатному расписанию вуза (заведующий кафедрой, доцент, старший
преподаватель, инженер-программист, специалист технической поддержки).

## Сборка

### Вариант 1: g++ (MSYS2 / MinGW-w64), без CMake

```bat
build.cmd
```

Скрипт собирает два файла: `build\worker_app.exe` и `build\worker_tests.exe`.

### Вариант 2: CMake

```bat
cmake -S . -B build
cmake --build build
```

Требуется компилятор с поддержкой C++17 (проверено на g++ 14.2.0).

## Запуск

```bat
worker_app                     :: интерактивный ввод с клавиатуры
worker_app --demo              :: демонстрационный набор данных
worker_app --file data\workers_demo.txt   :: загрузка из файла
```

Дополнительные параметры:

- `--min-experience <лет>` — порог стажа (в режимах `--demo` и `--file` по умолчанию 3);
- `--current-year <год>` — расчётный год (по умолчанию системный);
- `--help` — справка.

## Проектные решения

- **Инкапсуляция.** Все поля закрыты; изменение возможно только через сеттеры,
  которые валидируют данные и не оставляют объект в частично изменённом
  состоянии (метод `edit` сначала проверяет все значения, потом присваивает).
- **Валидация.** Пустые ФИО и должность, отрицательный оклад, год вне диапазона
  `1900…текущий год` отклоняются исключением `std::invalid_argument`.
- **Адаптация под организацию.** Должности и оклад вынесены в данные
  (`data/workers_demo.txt`), а не в код, — набор легко заменить на штатное
  расписание конкретного подразделения.
- **Переносимость.** Год берётся из системных часов (`localtime_s`/`localtime_r`),
  консоль Windows переключается в UTF-8 для корректного русского текста.
